#### ⏻安装部署
1. 确保急停按钮是按下去的
2. 一定按照说明接好线（国内，电源适配器不要动，默认处理好的230v档位不要拨动，不然可能会击穿适配器。
3. 上电之后，你会发现state的绿灯亮了或者在闪烁，这是正常现象。然后复位急停按钮（急停按钮有个reset），这个时候，机械臂的power灯会亮（变红）
#### 💻网络配置
（目前是基于macos进行配置的）
核心就是让电脑和机械臂（控制器）的IP地址处于**同一网段**。具体操作如下：
1.  **从Mac的 `系统设置` 进入**。
2.  点击 **`网络`** → 确保左侧选择了你连接机械臂时正在用的网络服务。
3. 进入对应网络服务里，点击详细信息可以进行网段设置：
	- **`配置IPv4`**：从默认的“使用DHCP”改为 **`手动`**。
	- **`IP地址`**：根据机械臂的出厂IP填写。例如，你机械臂底部的标签上是 `192.168.1.185`，那么你的电脑IP地址可以设为 `192.168.1.100`，只要保证它们前三位一致、最后一位不同就行。
	- **`子网掩码`**：填入 `255.255.255.0`。
	- **`路由器`**：可以暂时留空。
4. 测试连通性:  设置完成后，打开Mac电脑的“终端”应用，输入 `ping [机械臂的IP地址]`（例如 `ping 192.168.1.185`）。如果看到类似 “64 bytes from 192.168.1.185: icmp_seq=0 ttl=64 time=0.234 ms” 这样的回复信息，就表示网络已经成功连接。

### 🌐 浏览器访问与控制

成功 `ping` 通后，就可以用Mac上的谷歌浏览器（Chrome）访问机械臂的控制界面了。在浏览器地址栏输入 `http://[机械臂IP地址]:18333`，例如 `http://192.168.1.185:18333` 就能看到 **UFACTORY Studio** 的控制界面了。
### ⚙️ 修改机械臂IP（进阶操作）

如果Wi-Fi路由器的网段也是`192.168.1.xxx`，那就不需要改机械臂的IP。不过，如果想让它和你所在局域网（例如 `192.168.2.xxx`）匹配上，避免以后频繁切换电脑网络，也可以按照以下步骤操作：
1. **直连配置**：先用网线将电脑和机械臂控制器直连，设置好电脑的IP（例如 `192.168.1.100`）。
2. **浏览器访问**：在浏览器中打开 UFACTORY Studio 界面。
3. **修改IP**：依次进入 **`设置`** → **`网络设置`**。
4. **保存重启**：将机械臂的IP地址修改为与你的局域网相匹配的地址（例如 `192.168.2.88`），点击保存并重启机械臂即可。

### 💡 故障排查指南
如果遇到网络问题，可以按照这个思路排查：
- **检查网线**：确认网线是否插紧，以及以太网端口上的指示灯是否在闪烁[](https://www.ufactory.cc/wp-content/uploads/2023/05/Lite6-User-Manual-V2.0.0.pdf#5#4)。
- **检查IP**：确认电脑IP是否和机械臂IP处于同一网段，且地址没有冲突[](https://www.ufactory.cc/wp-content/uploads/2023/05/Lite6-User-Manual-V2.0.0.pdf#5#4)。
- **关闭代理**：在 Mac 的“系统设置” → “网络” → “详细信息” → “代理”里，确保所有代理选项都是关闭的，否则可能影响通信。
- **更换浏览器**：如果浏览器访问不了，可以尝试清理浏览器缓存或使用无痕模式。
- **查看标签**：如果忘了机械臂的IP，可以查看控制器侧面的标签[](https://zh-tw.manuals.plus/ufactory/lite-6-robotic-arm-manual)。
- **Ping 127.0.0.1**：如果`ping`机械臂IP不通，可以先试试`ping 127.0.0.1`，这个命令是用来测试电脑自身网络协议栈是否正常的。如果不通，可能需要重启电脑或检查网络设置。
