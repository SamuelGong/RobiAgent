# 关键配置参数说明

## 1. 普遍设置

### 1.1 相机相关

`config.yml`内字段：`physical/camera/[left|right]/`

| 参数名      | 含义              |   默认值    |
|----------|-----------------|:--------:|
| `fx`     | 相机 x 方向焦距（像素单位） | `500.0`  |
| `fy`     | 相机 y 方向焦距（像素单位） | `500.0`  |
| `cx`     | 相机主点 x 坐标       | `320.0`  |
| `cy`     | 相机主点 y 坐标       | `240.0`  |
| `id`     | 摄像头编号           |   `0`    |
| `width`  | 采集图像宽度          |  `640`   |
| `height` | 采集图像高度          |  `480`   |
| `fps`    | 摄像头目标帧率         |   `60`   |

### 1.2 机械臂相关

`config.yml`内字段：`physical/arm/[left|right]/`

| 参数名         | 含义                       |                               默认值                               |
|-------------|--------------------------|:---------------------------------------------------------------:|
| `id`        | 名字（用于复用 calibration 的结果） |                                无                                |
| `port`      | 对应 USB 接口路径              |                                无                                |
| `urdf_path` | URDF 文件路径（可选，新版人脸追踪要用）   |    thirdparty/lerobot/so101/description/so101_new_calib.urdf    |

### 1.3 智能体编排相关

`config.yml`内字段：`agent/`

| 参数名                      | 含义                      | 默认值 |
|--------------------------|-------------------------|:---:|
| `max_num_tasks_launched` | 最多用几个子任务完成一个任务          | 20  |
| `max_workers`            | 同一时间能有最多几个子任务同时在跑       |  4  |
| `task_retry_time_limit`  | 每个子任务若失败，重试几次 |  0  |

## 2. 任务特定设置

### 2.1 旧版人脸跟踪

#### 2.1.1 逆运动学相关

`config.yml`内字段：`task/face_track/geometry`

| 参数名                  | 含义                                          |           默认值            |
|----------------------|---------------------------------------------|:------------------------:|
| `face_width_m`       | 假设的真实人脸宽度，用于单目估深度                           |          `0.18`          |
| `pan_axis_cam`       | `shoulder_pan` 轴点在相机坐标系中的位置 `(x, y, z)`，单位米 |  `(0.055, 0.30, -0.13)`  |
| `pan_to_lift_home`   | 从 `pan` 轴点到 `lift` 轴点的固定偏移，单位米（相机坐标系）       | `(0.00, -0.0075, 0.03)`  |
| `lift_to_phone_home` | 从 `lift` 轴点到手机中心的固定偏移，单位米（相机坐标系）            |   `(0.00, 0.00, 0.12)`   |
| `screen_normal_home` | home 姿态下屏幕法向方向向量（相机坐标系）                     |   `(0.00, 0.00, 0.12)`   |

> 相机坐标系：镜头为坐标原点；（镜头看出去）X 向右、Y 向下、Z 向前

#### 2.1.2 其他

`config.yml`内字段：`task/face_track`

| 参数名                        | 含义                            |               默认值                |
|----------------------------|-------------------------------|:--------------------------------:|
| `model_path`               | 人脸识别库具体使用的模型                  | "thirdparty/face_detector.task"  |
| `control_hz`               | 控制指令发送频率                      |              `50.0`              |
| `alpha_xyz`                | 人脸 3D 坐标的 EMA 平滑系数（0-1，越小越平滑） |              `0.18`              |
| `lost_timeout`             | 丢失人脸多久后判定为丢失（丢失时将返回 home 姿态）  |              `2.0`               |
| `min_detection_confidence` | 人脸检测最小置信度阈值                   |              `0.6`               |
| `track_duration_s`         | 跟踪持续时长                        |              `25.0`              |
| `hold_last_on_timeout`     | 到达定时后是否保持最后位姿                 |              `True`              |

对应数据类：`robiagent/backend/arm/face_track.py`中的`InternalParams`。

| 参数名                  | 含义                              |   默认值   |

| `lift_units_per_rad` | `lift` 每弧度对应的关节单位数              | `45.0`  |

| `lift_bias`          | `lift` 的静态偏置（用于校准几何零点；单位：关节单位数） |  `0.0`  |
| `yaw_deadband_rad`   | 水平方向对准容差（弧度，0.02 rad ≈ 1.15°）   | `0.02`  |
| `pitch_deadband_rad` | 俯仰方向对准容差（弧度）                    | `0.02`  |
| `max_pan_step`       | 单次更新允许的最大 `pan` 移动关节单位数         |  `5.0`  |
| `max_lift_step`      | 单次更新允许的最大 `lift` 移动关节单位数        |  `5.0`  |
| `pan_min_offset`     | 相对 HOME 的 `pan` 最小移动关节单位数       | `-45.0` |
| `pan_max_offset`     | 相对 HOME 的 `pan` 最大移动关节单位数       | `45.0`  |
| `lift_min_offset`    | 相对 HOME 的 `lift` 最小移动关节单位数      | `-45.0` |
| `lift_max_offset`    | 相对 HOME 的 `lift` 最大移动关节单位数      | `45.0`  |
| `face_x_s`           | 人脸 X 坐标的初始值（相机坐标系；不重要）          | `-0.05` |
| `face_y_s`           | 人脸 Y 坐标的初始值（相机坐标系；不重要）          |  `0.0`  |
| `face_z_s`           | 人脸 Z 坐标的初始值（相机坐标系；不重要）          |  `0.8`  |

### 2.2 新版人脸跟踪

#### 2.2.1 逆运动学相关

`config.yml`内字段：`task/face_track_new/geometry`

| 参数名                  | 含义                                 |         默认值         |
|----------------------|------------------------------------|:-------------------:|
| `face_width_m`       | 假设的真实人脸宽度，用于单目估深度                  |       `0.18`        |
| `camera_origin_in_ik_m`  | 相机镜头在机械臂坐标系中的位置 `(x, y, z)`，单位米 | `(0.0, 0.17, 0.36)` |

> 机械臂坐标系：机械臂基座中某一点为坐标原点；（朝机械臂伸出方向）X 向前、Y 向左、Z 向上

| 参数名                          | 含义                                                                        |               默认值               |
|------------------------------|---------------------------------------------------------------------------|:-------------------------------:|

| `control_hz`                 | 控制指令发送频率                                                                  |             `50.0`              |

| `target_plane_below_eye_m`   | 目标屏位在竖直方向上低于眼点的距离（米），与 `desired_eye_distance_m` 共同决定水平对准距离                |             `0.05`              |
| `ik_mode`                    | 逆解策略：`soft` 不校验 FK 残差；`hard` 须在容差内才下发；`hard_bisection` 在不可解时对当前与目标位姿做二分逼近 |        `hard_bisection`         |

| `target_pos_deadband_m`      | 目标位置变化死区，单位米；小于该距离的目标位置变化会被忽略                                             |             `0.004`             |
| `target_normal_deadband_deg` | 目标屏幕法向变化死区，单位度；小于该角度的法向变化会被忽略                                             |              `0.8`              |
| `target_max_pos_step_m`      | 每个控制周期允许的最大目标位置变化量，单位米；用于限制目标位置移动速度                                       |             `0.010`             |
| `target_max_normal_step_deg` | 每个控制周期允许的最大目标屏幕法向变化量，单位度；用于限制目标姿态变化速度                                     |              `2.0`              |

### 2.3 语音播报

`config.yml`内字段：`task/vocal_intro`

| 参数名           | 含义              |       默认值        |
|---------------|-----------------|:----------------:|
| `text`        | 待播报的文字内容        | 你好，很高兴向你介绍这款新产品！ |
| `chunk_size`  | 每次上行发送多少字符      |        8         |
| `chunk_delay` | 两块之间的延迟（模拟真人讲话） |       0.1        |
