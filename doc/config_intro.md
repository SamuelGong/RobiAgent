# 关键配置参数说明

## 1. 普遍设置

### 1.1 相机相关

| 参数名         | 含义      |     默认值 |
| ----------- | ------- |--------:|
| `fx`           | 相机 x 方向焦距（像素单位）   | `500.0` |
| `fy`           | 相机 y 方向焦距（像素单位）   | `500.0` |
| `cx`           | 相机主点 x 坐标         | `320.0` |
| `cy`           | 相机主点 y 坐标         | `240.0` |
| `camera_id` | 摄像头编号   |     `0` |
| `width`     | 采集图像宽度  |   `640` |
| `height`    | 采集图像高度  |   `480` |
| `fps`       | 摄像头目标帧率 |    `30` |

### 1.2 机械臂相关

| 参数名    | 含义                       | 默认值 |
|--------|--------------------------|----:|
| `id`   | 名字（用于复用 calibration 的结果） |   无 |
| `port` | 对应 USB 接口路径              |   无 |

## 2. 任务特定设置

### 2.1 人脸跟踪

#### 2.1.1 机械臂相关

| 参数名            | 含义                |                      默认值 |
| -------------- | ----------------- |-------------------------:|
| `face_width_m` | 假设的真实人脸宽度，用于单目估深度 |                   `0.18` |
| `pan_axis_cam`       | `shoulder_pan` 轴点在相机坐标系中的位置 `(x, y, z)`，单位米 |   `(-0.05, 0.30, -0.12)` |
| `pan_to_lift_home`   | 从 `pan` 轴点到 `lift` 轴点的固定偏移，单位米              | `(0.00, -0.0075, 0.035)` |
| `lift_to_phone_home` | 从 `lift` 轴点到手机中心的固定偏移，单位米                   |    `(0.00, -0.08, 0.16)` |
| `screen_normal_home` | home 姿态下屏幕法向方向向量                            |   `(0.00, -0.08, 0.16)` |

#### 2.1.3 其他

| 参数名                        | 含义                    |    默认值 |
| -------------------------- | --------------------- |-------:|
| `control_hz`               | 控制指令发送频率              | `50.0` |
| `alpha_xyz`                | 人脸 3D 坐标的 EMA 平滑系数    | `0.18` |
| `lost_timeout`             | 丢失人脸多久后判定为丢失          |  `2.0` |
| `min_detection_confidence` | 人脸检测最小置信度阈值           |  `0.6` |
| `track_duration_s`         | 跟踪持续时长；到时后停止跟踪并保持最后位姿 | `25.0` |
| `hold_last_on_timeout`     | 到达定时后是否保持最后位姿         | `True` |

## 3. 目前设计不可直接设置的参数（硬编码）

### 3.1 机械臂相关

| 参数名                  | 含义                     |     默认值 |
| -------------------- | ---------------------- |--------:|
| `pan_sign`           | `shoulder_pan` 控制方向符号  |   `1.0` |
| `lift_sign`          | `shoulder_lift` 控制方向符号 |   `1.0` |
| `pan_units_per_rad`  | `pan` 每弧度对应的关节单位换算系数   |  `45.0` |
| `lift_units_per_rad` | `lift` 每弧度对应的关节单位换算系数  |  `45.0` |
| `pan_bias`           | `pan` 的静态偏置            |   `0.0` |
| `lift_bias`          | `lift` 的静态偏置           |   `0.0` |
| `yaw_deadband_rad`   | 水平方向角度死区               |  `0.02` |
| `pitch_deadband_rad` | 俯仰方向角度死区               |  `0.02` |
| `max_pan_step`       | 单次更新允许的最大 `pan` 步长     |   `5.0` |
| `max_lift_step`      | 单次更新允许的最大 `lift` 步长    |   `5.0` |
| `pan_min_offset`     | 相对 HOME 的 `pan` 最小偏移   | `-45.0` |
| `pan_max_offset`     | 相对 HOME 的 `pan` 最大偏移   |  `45.0` |
| `lift_min_offset`    | 相对 HOME 的 `lift` 最小偏移  | `-45.0` |
| `lift_max_offset`    | 相对 HOME 的 `lift` 最大偏移  |  `45.0` |
| `face_x_s` | 平滑后人脸 X 的初始值 | `-0.05` |
| `face_y_s` | 平滑后人脸 Y 的初始值 |   `0.0` |
| `face_z_s` | 平滑后人脸 Z 的初始值 |   `0.8` |
